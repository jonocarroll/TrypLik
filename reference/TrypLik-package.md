# TrypLik: Calculates Tryptase Variant Likelihoods

Calculates tryptase variant (alpha, beta) likelihoods based on counts
using a wrapped C method. Preprocessing of cram files is provided as
both bash scripts and R wrappers. A detailed description of the method
employed is provided as a vignette. Contact HIBio to learn more about
our tryptase program and services provided.
